手机本地运行

Agent 和 WebUI 运行在手机上，无需电脑或远端 Hermes 服务。使用云模型时仍需联网并配置服务商。

聊天与终端

查看流式回复和 Markdown；需要运行命令时，从输入框旁打开终端。模型与 API Key 仍可在网页设置中配置。

安装到手机

处理器
arm64-v8a
系统
Android 7.0 或更高版本
安装方式
下载 APK 后侧载安装
  1. 下载安装包

    在 GitHub Releases 的 Assets 中找到 APK 和对应的 SHA-256 校验文件。

  2. 打开 APK

    按系统提示允许安装。若已安装使用同一长期签名的版本，可直接覆盖升级。

  3. 配置模型

    打开 App，等待首次运行解包，在设置中选择模型服务商和模型。
